## ✨ About

This is my personal portfolio website, designed and developed to showcase my software engineering projects, technical skills, experience, and background.

The site focuses on a modern, interactive experience with smooth animations, responsive layouts, internationalization, and accessible UI.

## 🚀 Features

* Responsive design across desktop, tablet, and mobile
* Modern animations and transitions using GSAP
* Smooth scrolling
* English and Arabic localization
* RTL support
* Project showcase with image carousels
* Interactive navigation and menu transitions
* SEO-friendly metadata
* Optimized images using Next.js Image
* Contact and social links
* Custom preloader and page transitions

## 🛠 Tech Stack

| Technology               | Purpose                                      |

## 📦 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/NullUser3/Third-Portfolio.git
cd Third-Portfolio

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser to view the website.

## 🚀 Building for Production

Create an optimized production build:

```bash
npm run build
```

Run the production server:

```bash
npm run start
```

## 🌍 Internationalization

The portfolio currently supports:

* 🇬🇧 English
* 🇸🇦 Arabic

Arabic uses RTL layout support where appropriate.

Translations are managed using `next-intl`.
